# Imagens de Torres Selecionadas do STN-PLAD
***

As imagens nesse diretório foram selecionadas por possuirem objetos de torres de transmissão. Devido a limitações de versionamento no GitHub, os arquivos de rótulos e de imagens não foram versionados, porém podem ser obtidos a partir do script ```selecao-imagens-com-torres.ipynb```.
