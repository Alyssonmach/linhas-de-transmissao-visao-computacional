# BASE-DETECTION (Organização do Diretório)
***

Esse diretório é reservado para armazenar as imagens descompactadas do BASE-DETECTION Dataset, as imagens e os rótulos não foram versionados devido a não possibilidade de versionar todos os arquivos de imagens e rótulos por exercer um limite estabelecido pelo GitHub.

Para baixar e organizar os dados, siga as instruções do arquivo ```README.md``` disponibilizado no diretório ```datasets-compactados```.

Após ler a documentação solicitada, mantenha apenas os diretórios ```test```, ```train``` e ```valid```, os demais arquivos presentes na pasta compactada podem ser descartados.
