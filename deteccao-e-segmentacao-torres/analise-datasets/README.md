# Conjuntos de Imagens Selecionados para Análise
***

Conjuntos de imagens passíveis de serem utilizados ao longo do desenvolvimento do projeto.

* [TTPLA Dataset](https://github.com/R3ab/ttpla_dataset): ```279 imagens de torres de transmissão```
    "TTPLA" é um conjunto de imagens que compreende uma coleção de capturas aéreas de Torres de Transmissão (TTs) e Linhas de Energia (PLs). As marcações presentes nesse conjunto de imagens correspondem à segmentação por instância das torres, linhas e componentes do sistema de transmissão elétrica.

* [STN PLAD Dataset](https://github.com/andreluizbvs/PLAD): ```131 imagens de torres de transmissão```
    "STN PLAD" é um conjunto de imagens de alta resolução do mundo real, que abrange diversos componentes de linhas de energia de alta tensão. As marcações presentes nesse conjunto de imagens consistem em caixas delimitadoras que englobam torres e componentes das linhas de transmissão. As imagens apresentam variações em termos de tamanho (resolução), orientação, iluminação, ângulo e plano de fundo.

* [COT SAT](https://universe.roboflow.com/cao-the-ktpc-udrjd/cot-sat-txqdh): ```83 imagens de torres de transmissão```
    "COT-SAT" é um conjunto de imagens composto por uma variedade de capturas obtidas da internet, retratando torres de transmissão de alta tensão. As anotações presentes nesse conjunto de imagens envolvem a segmentação por instância das torres de transmissão. As imagens apresentam uma resolução mais modesta e uma quantidade reduzida quando comparadas com outros conjuntos disponíveis.
    
* [DT COT SAT CT](https://universe.roboflow.com/bdpc-ai-gd2/dt-cot-sat-ct): ```50 imagens de torres de transmissão```
    "DT COT SAT" é um conjunto de imagens que deriva de uma coleção de capturas variadas obtidas pela internet, todas retratando torres de transmissão de alta tensão. Este conjunto é uma versão similar ao anterior, ou seja, o COT SAT. As anotações contidas nesse conjunto de imagens abrangem a segmentação por instâncias das torres de transmissão. Semelhante ao COT SAT, as imagens exibem uma resolução mais modesta e uma quantidade reduzida em comparação com outros conjuntos de imagens disponíveis.
    
* [Daychongset110](https://universe.roboflow.com/khpcdoituonggd2/daychongset110): ```61 imagens de torres de transmissão```
    "Daychongset110" é um conjunto de imagens originado de uma coleção de capturas feitas por drones, focalizando os cabos para-raios presentes em linhas de alta tensão. As marcações contidas nesse conjunto de imagens consistem em caixas delimitadoras que cercam os cabos para-raios. O traço distintivo desse conjunto de imagens em relação aos demais é que as fotografias foram tiradas em proximidade das torres, com pontos de observação que variam entre uma perspectiva ascendente e descendente da visualização dessas linhas.

* [CSAT CT](https://universe.roboflow.com/qbpcluoi110gd1/csat_ct): ```208 imagens de torres de transmissão```
    "CSAT CT" é um conjunto de imagens originado a partir de uma coleção de capturas aéreas feitas por drones, com foco nas torres de transmissão de alta tensão. As marcações presentes nesse conjunto de imagens consistem em caixas delimitadoras que englobam as diversas torres. Este conjunto de dados guarda semelhanças significativas com o STN PLAD e o TTPLA, sendo que os pontos de observação são frequentemente capturados ao redor ou acima das torres.

* [Base Detection](https://universe.roboflow.com/shandong-university-zvicd/base-detection-zyh6x): ```58 imagens de torres de transmissão```
    "Base Detection" é um conjunto de imagens originado a partir de uma coleção de capturas feitas das bases das torres de transmissão de alta tensão. As marcações presentes nesse conjunto de imagens consistem em caixas delimitadoras que englobam árvores, solo erodido ou itens inflamáveis localizados na base das torres de transmissão. Este conjunto de imagens é útil por conter imagens que focam mais na região da base das torres de transmissão, contribuindo para uma maior variabilidade dos dados.

* [110 NHANDIEN COTSAT](https://universe.roboflow.com/tthpc/110_nhandien_cotsat): ```106 imagens de torres de transmissão```
    "110 NHANDIEN COTSAT" originou-se a partir de uma coleção de capturas aéreas realizadas por drones, com foco nas torres de transmissão de alta tensão. As marcações presentes nesse conjunto de imagens consistem em segmentações por instância que englobam as diversas torres. Este conjunto de dados apresenta semelhanças significativas com o STN-PLAD e o TTPLA, com os pontos de observação frequentemente capturados ao redor ou acima das torres.

* [Tower Joint](https://universe.roboflow.com/yuyang-li/tower_jointv1): ```1008 imagens de torres de transmissão```
    "Tower Joint" é um conjunto de imagens originado a partir de uma coleção de capturas aéreas feitas por drones, com foco em detectar as juntas presentes nas treliças das torres de transmissão, assim como os lados que conectam essas juntas na vertical. As marcações presentes nesse conjunto de imagens consistem em caixas delimitadoras dos elementos mencionados, localizados nos pontos de cruzamento das treliças das torres. Este conjunto de imagens é valioso por conter imagens que capturam regiões próximas das torres de transmissão, contribuindo para uma maior variedade nos dados.
    
* [Transmission System](https://universe.roboflow.com/power-tower/transimission-system): ```913 imagens de torres de transmissão```
    "Transmission System" é um conjunto de imagens originado a partir de simulações digitais e manipulações de cenários de torres de transmissão em laboratórios. As marcações presentes nesse conjunto de imagens consistem em caixas delimitadoras das torres de transmissão. Este conjunto de imagens é valioso por conter imagens simuladas digitalmente e em cenários de laboratório, o que contribui para o aumento da quantidade de dados por meio de imagens artificiais.
