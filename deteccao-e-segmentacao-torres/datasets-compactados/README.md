# Aquisição do Conjunto de Imagens Original
***

### Baixar os COnjuntos de Imagens Compactados
***

* [TTPLA Dataset](https://github.com/R3ab/ttpla_dataset).
* [STN-PLAD](https://github.com/andreluizbvs/PLAD).
* [COT-SAT](https://universe.roboflow.com/cao-the-ktpc-udrjd/cot-sat-txqdh).
* [DT-COT-SAT](https://universe.roboflow.com/bdpc-ai-gd2/dt-cot-sat-ct).
* [Daychongset110](https://universe.roboflow.com/khpcdoituonggd2/daychongset110).

### Script de Descompactação dos Conjuntos de Imagens
***

* Execute o script ```descompactar.py``` para descompactar o arquivo ```.zip``` com as imagens originais e rótulos de ambos conjuntos de imagens.
* A partir da pasta que contém as imagens e os arquivos de dados com os rótulos descompactados, renomeie-os para ```TTPLA-dataset```, ```STN-PLAD``` e ```COT-SAT```, respectivamente.
