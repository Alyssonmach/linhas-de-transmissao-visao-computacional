# Aquisição do Conjunto de Imagens Original
***

* As imagens compactadas foram adquiridas do repositório oficial do conjunto de imagens [TTPLA Dataset](https://github.com/R3ab/ttpla_dataset).
* Execute o script ```descompactar.py``` para descompactar o arquivo ```.zip``` com as imagens originais.
* A partir da pasta que contém as imagens e os arquivos de dados com os rótulos, renomeie-o para ```TTPLA-dataset```.
