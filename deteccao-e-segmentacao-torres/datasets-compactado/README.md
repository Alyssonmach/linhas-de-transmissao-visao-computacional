# Aquisição do Conjunto de Imagens Original
***

* As imagens compactadas do TTPLA foram adquiridas do repositório oficial do conjunto de imagens [TTPLA Dataset](https://github.com/R3ab/ttpla_dataset).
* As imagens compactadas do STN-PLAD foram adquiridas do repositório oficial do conjunto de imagens [STN-PLAD](https://github.com/andreluizbvs/PLAD).
* As imagens compactadas do COT-SAT foram adquiridas do repositório oficial do conjunto de imagens [COT-SAT](https://universe.roboflow.com/cao-the-ktpc-udrjd/cot-sat-txqdh).
* Execute o script ```descompactar.py``` para descompactar o arquivo ```.zip``` com as imagens originais e rótulos de ambos conjuntos de imagens.
* A partir da pasta que contém as imagens e os arquivos de dados com os rótulos descompactados, renomeie-os para ```TTPLA-dataset```, ```STN-PLAD``` e ```COT-SAT```, respectivamente.
