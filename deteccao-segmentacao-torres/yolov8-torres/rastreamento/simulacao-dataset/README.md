# Dados de simulação para rastreamento

Este diretório é destinado aos vídeos e às imagens usados nos testes de rastreamento em ambiente simulado. O notebook [`conversao-videos.ipynb`](conversao-videos.ipynb) documenta a conversão de vídeos em quadros.

Os arquivos de vídeo e as imagens geradas não são versionados pelo Git. Quando disponíveis localmente, mantenha-os nesta pasta e ajuste os caminhos no notebook.
