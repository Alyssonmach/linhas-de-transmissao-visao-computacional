# Conjunto de Imagens do Ambiente Simulado
***

Esse conjunto de imagens se refere ao ambiente simulado utilizado para otimizar os algoritmos de rastreamento para identificação das torres. Nele, há um arquivo ```videos-referencia.zip```, contendo alguns vídeos de referência feitos para os testes dos algoritmos de rastreio. Como resultado do scritp ```conversao-videos.pynb```, foi gerado um conjunto de imagens e salvo como  ```imagens.zip```.
