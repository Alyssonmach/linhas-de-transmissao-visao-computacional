# Conjunto de Teste
***

Este diretório contém dois principais subdiretórios: ```imagens``` e ```videos```. Cada um desse subdiretórios contém amostras de imagens e vídeos de torres de transmissão em diferentes formatos e cenários possíveis, para que os modelos treinados possam ser testados com uma maior generabilidade possível de cenários de aplicação.
