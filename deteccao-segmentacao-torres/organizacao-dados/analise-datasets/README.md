# Conjuntos de imagens analisados

Os notebooks deste diretório inspecionam a organização, as imagens e as anotações de diferentes bases públicas. As quantidades abaixo são as registradas no levantamento do projeto; não representam imagens únicas entre bases nem necessariamente o total usado em cada cenário de treinamento.

| Conjunto | Quantidade registrada | Descrição resumida |
| --- | ---: | --- |
| [TTPLA Dataset](https://github.com/R3ab/ttpla_dataset) | 279 imagens | Capturas aéreas com torres, linhas de energia e componentes, com anotações de segmentação por instância. |
| [STN PLAD](https://github.com/andreluizbvs/PLAD) | 131 imagens | Imagens de componentes de linhas de alta tensão, com caixas delimitadoras e variação de resolução, iluminação, orientação e fundo. |
| [COT SAT](https://universe.roboflow.com/cao-the-ktpc-udrjd/cot-sat-txqdh) | 83 imagens | Imagens de torres de alta tensão, anotadas para segmentação por instância. |
| [DT COT SAT CT](https://universe.roboflow.com/bdpc-ai-gd2/dt-cot-sat-ct) | 50 imagens | Conjunto relacionado ao COT SAT, com imagens de torres e anotações de segmentação por instância. |
| [Daychongset110](https://universe.roboflow.com/khpcdoituonggd2/daychongset110) | 61 imagens | Capturas próximas de torres, com foco em cabos para-raios e variação de perspectiva. |
| [CSAT CT](https://universe.roboflow.com/qbpcluoi110gd1/csat_ct) | 208 imagens | Capturas aéreas de torres de alta tensão, anotadas com caixas delimitadoras. |
| [Base Detection](https://universe.roboflow.com/shandong-university-zvicd/base-detection-zyh6x) | 58 imagens | Imagens das bases de torres, incluindo elementos do solo e da vegetação, úteis para ampliar a variedade visual. |
| [110 NHANDIEN COTSAT](https://universe.roboflow.com/tthpc/110_nhandien_cotsat) | 106 imagens | Capturas aéreas de torres com anotações de segmentação por instância. |
| [Tower Joint](https://universe.roboflow.com/yuyang-li/tower_jointv1) | 1.008 imagens | Imagens próximas das treliças, anotadas para localizar juntas e segmentos de conexão. |
| [Transmission System](https://universe.roboflow.com/power-tower/transimission-system) | 913 imagens | Imagens de torres geradas por simulação digital e ambientes de laboratório, com caixas delimitadoras. |

As bases são independentes e usam esquemas de anotação distintos. Consulte os notebooks e a documentação de origem antes de combinar os dados ou comparar contagens.
