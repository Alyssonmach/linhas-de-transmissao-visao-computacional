# Detecção, segmentação e rastreamento

Esta área reúne os experimentos de visão computacional aplicados à análise de torres de transmissão. O trabalho combina a organização dos dados com o treinamento de modelos e a avaliação qualitativa em imagens e vídeos.

## Conteúdo

- [`organizacao-dados/`](organizacao-dados/): análise, organização e refinamento dos conjuntos de imagens.
- [`yolov8-torres/`](yolov8-torres/): treinamento e inferência com YOLOv8, avaliação dos cenários e experimentos de rastreamento.

As instruções específicas estão nos READMEs de cada subdiretório. Bases, pesos e mídias de teste podem estar ausentes do Git por serem arquivos volumosos.
